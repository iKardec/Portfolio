## 📋 Sobre o Projeto

Este é um portfólio profissional desenvolvido para apresentar as competências, experiências e projetos de **Alan Kardec Lima Campos Júnior**. O site foi construído com foco em:

- ✨ **UI/UX Premium** - Design moderno com glassmorphism, animações e efeitos visuais
- 📱 **Responsividade Total** - Funciona perfeitamente em desktop, tablet e mobile
- ⚡ **Performance Otimizada** - Código modular e otimizado para carregamento rápido
- ♿ **Acessibilidade** - Atributos ARIA e semântica HTML5 para todos os usuários
- 🎨 **Paleta Laranja/Preto** - Identidade visual consistente e profissional

## ✨ Funcionalidades

### 🎨 Design
- **Glassmorphism** - Cards com efeito de vidro e blur
- **Partículas Animadas** - Background com partículas flutuantes
- **Gradientes** - Uso de gradientes para destaque visual
- **Glow Effects** - Brilhos pulsantes nos elementos de destaque

### 🔄 Interatividade
- **Navegação por Tabs** - Transições suaves entre seções
- **Tilt Effect** - Cards que inclinam com o movimento do mouse
- **Scroll Reveal** - Elementos aparecem conforme o scroll
- **Progress Bar** - Indicador de progresso de leitura
- **Scroll to Top** - Botão para voltar ao topo

### 📱 Responsividade
- **Mobile-First** - Design adaptado para todos os dispositivos
- **Touch Friendly** - Navegação otimizada para touch
- **Scroll Horizontal** - Menu de navegação com scroll no mobile

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/iKardec/Portfolio.git
   ```

2. **Abra o arquivo `index.html`** em qualquer navegador moderno

3. **Ou use um servidor local** (recomendado para desenvolvimento)
   ```bash
   # Com Python
   python -m http.server 8000
   
   # Com Node.js (live-server)
   npx live-server
   ```
